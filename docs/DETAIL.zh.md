# 论文写作模式

给 DeepSeek Harness 增加一个专门用于论文写作的智能体模式。选中后，会话会获得一份常驻的学术写作方法提示词，以及读写文件、检索文献、编译 LaTeX、交付文档所需的工具。

## 适合谁

- 正在写课程论文、学位论文、期刊论文、会议论文、开题报告或基金申请的人
- 需要的不只是润色，还包括选题收敛、文献综述写法、章节结构与论证检查的人
- 用 LaTeX 写作，希望有人能读日志、修编译错误、检查版式的人
- 希望建议能落到「具体改成什么」而不是泛泛评价的人

## 覆盖内容

常驻系统提示按写作阶段组织，主要包括：

| 环节 | 提供的建议 |
|---|---|
| 对齐 | 先判断阶段与约束，只问影响结论的问题，给方案时说明代价 |
| 选题 | 研究问题四问、三类价值区分、可行性评估、宽题到可操作题目的三档收敛、候选题目与风险 |
| 文献 | 检索策略与数据库选择、引文追踪、文献矩阵、主题式综述写法、研究缺口收敛 |
| 结构 | IMRaD 与人文社科骨架、学位论文的绪论与结论要求、篇幅配比、反向大纲检查 |
| 语言 | 段落纪律、学术语体与限定词、常见病清单、中英典型问题、原句改句对照 |
| LaTeX | 引擎选择、工程布局、编译循环、日志排错、交叉引用与文献闭合、PDF 版式自检 |
| 规范 | 引用格式与转述、图表与数据溯源、学术伦理边界 |
| 投稿 | 自审清单、审稿意见逐条回应、选刊优先级、改稿顺序 |

## 工具

- 读写文件、目录检索、后台任务
- 命令行：Linux 与 macOS 用 bash，Windows 用 PowerShell（按宿主平台自动启用）
- Web 搜索与抓取，用于核对真实文献
- LaTeX 技能：引擎与工具链检查、构建脚本、工程模板、报错与投稿参考
- 决策记录技能：在论文仓库里维护只追加的决策日志与理论结构映射，改前读、改后写，并提供冲突检查程序
- 办公文档技能与 Office 渲染/转换，用于 docx 交付和 PDF 版面检查
- 任务清单、向用户提问、工作目录、交付声明
- 子代理与 workflow：并行检索、分章草稿、独立审稿

## 使用

1. 新建会话时在模式选择器里选择「论文写作」。
2. 也可以在 设置 → 通用 中把它设为之后会话的默认模式。
3. 已存在的会话不会切换模式，需要新建会话。

## 限制

- 提示词为中文撰写；用英文写作时会按目标语言输出正文，但方法说明仍是中文。
- TeX 工具链不随模式安装。模式会探测 xelatex、pdflatex、lualatex、latexmk、bibtex、biber，缺什么就报告什么。
- 检索工具可能返回不存在或信息有误的文献，正式引用前请以数据库原文核对。
- 模式依赖 DSH 安装自带的插件包（文件、检索、Office、子代理等）。安装时校验 `engines.dsh`，版本不满足会被拒绝，而不是装上一个无法激活的模式。
- 不代写、不伪造数据与文献、不协助规避查重。

## 安装与分享

- 直接安装目录：Plugins 页 **Add plugin** 选择包目录，或由 agent 用 `plugin_manager` 的 `install_bundle` 指向该目录。
- 安装打包文件：同一条 `install_bundle` 可以指向 `.tgz`；也可以用 `dsh plugin --profile <name> add ./dsh-paper-mode-<version>.tgz`。
- 通过 npm 分享：包名 `dsh-paper-mode`，发布后在 profile 里 `dsh plugin --profile <name> add dsh-paper-mode`。

## 修改

提示词与工具都在 `cordis.patch.yml` 的 `preset-paper` 行内；技能在 `skills/latex-paper/` 与 `skills/paper-decisions/`。改完后重新安装 bundle，新会话即使用新定义。`persona.prefix` 与 `suffix` 是模板，正文不要出现双层花括号，否则会被当作提示变量解析。
